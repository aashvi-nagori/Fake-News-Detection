# Fake News Detection Using Machine Learning

## Problem Statement
Fake news spread quickly on social media, which can mislead people and it also causes confusion for people to believe the news or not. Manually verifying every time-consuming and after unreliable. This project aims 
to automatically detect whether a news article is Real or Fake using machine learning techniques.

## Scope of the Project 
- Identify and classify news articles as Real or Fake automatically.
- Help users access trustworthy news efficiently.
- Can be extended to social media posts, vlogs, or another online platforms.
- Provides insights and evaluation matrices such as accuracy and confusion matrix for model performance.
- 
## Target Users 
- social media users who want to verify news articles.
- Students and researchers working on NLP or machine learning projects.
- News websites and content moderators who want to filter fake news.
  
## High-Level Features
- Preprocess news text:
  lowercasing, stopword removal, and stemming
- Convert text to TF-IDF vectors for machine learning
- Train models like logistic Regression or Naive Bayes for classification
- Input custom news text and get prediction (Real / Fake)
- Evaluate model using accuracy, confusion matrix, and other matrices.
